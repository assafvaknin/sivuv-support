# בדיקות מקומיות

כל שינוי נבדק במחשב המקומי לפני פתיחת Pull Request ולפני מיזוג ל־`main`.
GitHub אינו מריץ את הבדיקות.

הבדיקה `Validate support site` מוודאת:

- שכל ארבעת העמודים הציבוריים קיימים.
- שמבנה העמודים תקין בעברית ומימין לשמאל.
- שקיימים כותרת, תיאור, התאמה למובייל ואזור תוכן ראשי.
- שקישורים מקומיים, עוגנים וקובץ העיצוב אינם שבורים.
- שהפניות נגישות מסוג `aria-labelledby` מצביעות לרכיב קיים.
- שאין קישורים חיצוניים לא מאובטחים ב־HTTP.
- שנשמרו כללי מיקוד מקלדת, התאמה למסך קטן ומצב כהה.

להרצת כל הבדיקות:

```bash
scripts/verify_local.sh
```

לאחר הצלחה אפשר לפרסם ל־GitHub רק את תוצאת הבדיקה באמצעות
`scripts/report_local_status.sh success`. התוצאה מופיעה בשם `Local Mac verification`.

פרסום GitHub Pages נשאר תהליך נפרד. לאחר מיזוג ל־`main` יש לוודא שגם תהליך הפרסום הסתיים בהצלחה.
