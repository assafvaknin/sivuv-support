# הפעולה הבאה

לאחר אישור גרסת האפליקציה הבאה ב־App Store, להשוות בין התנהגות הגרסה שפורסמה לבין עמודי התמיכה, הפרטיות והתנאים.

יש לבדוק במיוחד:

- סנכרון iCloud ופתרון התנגשויות.
- גיבוי, שחזור ומחיקת נתונים.
- רכישת פרימיום ושחזור רכישה.
- כתובת התמיכה והקישורים המופיעים ב־App Store Connect.

אם אין שינוי בהתנהגות, אין צורך לשנות את הנוסח. אם יש שינוי, לעדכן את העמודים באותו Pull Request ולשנות את תאריך „עדכון אחרון”.
