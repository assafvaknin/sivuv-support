סטטוס: אתר תמיכה ציבורי פעיל בתחזוקה שוטפת.

- כתובת: <https://assafvaknin.github.io/sivuv-support/>
- פרסום: GitHub Pages מתוך `main`.
- עמודים: תמיכה, פרטיות, תנאי שימוש ונגישות.
