# מצב הפרויקט

סטטוס: אתר תמיכה ציבורי פעיל בתחזוקה שוטפת.

- כתובת: <https://assafvaknin.github.io/sivuv-support/>
- פרסום: GitHub Pages מתוך `main`.
- עמודים: תמיכה, פרטיות, תנאי שימוש ונגישות.
- מידע אישי: האתר סטטי ואינו מקבל את נתוני המשמרות מהאפליקציה.
- אימות מקור: `npm run ci`.

האתר נועד לתמוך באפליקציה ואינו מכיל את קוד האפליקציה. שינוי משפטי או שינוי בתיאור אופן שמירת הנתונים חייב להתאים להתנהגות האפליקציה בפועל.
