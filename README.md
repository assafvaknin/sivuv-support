# סבב – תמיכה ומדיניות פרטיות

אתר ציבורי לדפי התמיכה ומדיניות הפרטיות של אפליקציית „סבב – לוח משמרות אישי”.

האתר מתפרסם באמצעות GitHub Pages ואינו מכיל את קוד האפליקציה.

## בדיקה מקומית

```bash
scripts/verify_local.sh
```

הבדיקה אינה דורשת התקנת חבילות. היא מאמתת את מבנה העמודים, הקישורים המקומיים וכללי נגישות בסיסיים.
כל הבדיקות רצות על המחשב המקומי ולא ב־GitHub Actions. GitHub Pages נשאר אחראי רק לפרסום האתר.
